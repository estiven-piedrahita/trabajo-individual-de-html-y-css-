# CRUDScope - HTML MediaPanel

## Descripción General

CRUDScope es un gestor de tareas web basado en HTML5 semántico. El proyecto demuestra el uso completo de etiquetas semánticas modernas, multimedia integrada y buenas prácticas de estructura web.

El objetivo principal es crear una aplicación educativa que implemente el modelo CRUD (Crear, Leer, Actualizar, Eliminar) de forma clara y organizada.

## Características

- Interfaz intuitiva para gestión de tareas
- Estructura HTML5 completamente semántica
- Navegación clara entre secciones
- Galería multimedia para imágenes, audio y video
- Diseño responsivo adaptado a diferentes dispositivos
- Formularios funcionales para entrada de datos
- Tabla de tareas con acciones de actualización y eliminación

## Estructura del Proyecto

El proyecto está organizado en los siguientes archivos:

- `index.html` - Página principal con bienvenida y descripción del sistema
- `crear.html` - Formulario para crear nuevas tareas
- `listado.html` - Tabla con listado de tareas y opciones de gestión
- `multimedia.html` - Galería de multimedia (fotos, audio, video)
- `style.css` - Estilos CSS para todo el proyecto
- `README.md` - Este archivo

## Requisitos Cumplidos

### Estructura HTML

- Declaración correcta de doctype y atributo lang en español
- Meta charset UTF-8 y viewport
- Etiqueta base en el head
- Header, nav, main, section, article, aside y footer semánticos

### Contenido

- Título principal con h1
- Múltiples encabezados h2 y h3
- Párrafos descriptivos con texto enriquecido (strong, em, u, mark)
- Listas ordenadas y no ordenadas
- Tabla con datos de tareas
- Enlace interno a secciones

### Etiquetas Especiales

- `<abbr>` para explicar "CRUD"
- `<time>` para mostrar fechas
- `<address>` en el footer con información de contacto
- `<img>` con atributos alt, width y height

### Multimedia

- Sección dedicada para multimedia
- Reproductor de audio con controles
- Reproductor de video con controles
- Espacios para agregar fotografías

### Formularios

- Campos de entrada de texto
- Campo de fecha
- Desplegables para seleccionar opciones
- Área de texto para descripciones
- Botones de envío

## Cómo Usar

1. Abre `index.html` en tu navegador web
2. Usa el menú de navegación para moverte entre secciones
3. En "Crear Tareas" completa el formulario con los datos de tu tarea
4. En "Listado" verás la tabla con tareas de ejemplo
5. En "Multimedia" encontrarás espacios para fotos, audio y video

## Navegación

El sitio tiene una barra de navegación consistente en todas las páginas:

- HOME: Regresa a la página principal
- CREAR TAREAS: Accede al formulario de creación
- LISTADO: Ve todas las tareas
- MULTIMEDIA: Galería de recursos multimedia
